# Nadeeshan Wijesinghe — Portfolio

A personal portfolio website presenting my professional profile, technical skills, work experience, certifications, and projects as a System Engineer and IT professional.

**Live website:** [nadeeshanrw.github.io/Nadeeshan-Wijesinghe](https://nadeeshanrw.github.io/Nadeeshan-Wijesinghe/)

## About

I am an IT professional and Bachelor of Information Technology graduate with hands-on experience in system engineering. My interests include Linux system administration, DevOps, virtualization, containerization, infrastructure monitoring, and web development.

This website provides an overview of my professional background and a way to get in touch about opportunities and collaboration.

## Website Sections

- **About** — Professional introduction
- **Skills** — Technical skills grouped by area
- **Resume** — Education, experience, and activities
- **Certifications** — Selected certifications and learning achievements
- **Projects** — Examples of project work
- **Contact** — Contact details and a message form

## Features

- Responsive layout for desktop and mobile screens
- Light and dark themes, with the selected theme saved in the browser
- Animated elements and interactive skill categories
- Certification gallery with filtering and image previews
- Contact form prepared for EmailJS integration

## Technologies

- HTML5, CSS3, and JavaScript
- Bootstrap and Bootstrap Icons
- AOS, Typed.js, Glightbox, Isotope, and other vendor libraries
- EmailJS for contact-form delivery

## Run Locally

This is a static website. To view it locally:

1. Clone the repository:
   ```bash
   git clone https://github.com/NadeeshanRW/Nadeeshan-Wijesinghe.git
   ```
2. Open the project directory:
   ```bash
   cd Nadeeshan-Wijesinghe
   ```
3. Open `index.html` in a browser. For local development, you can also serve the directory using a local web server.

## Contact Form Configuration

The contact form uses EmailJS. To enable message delivery, create an EmailJS service and template, then configure the EmailJS public key, service ID, and template ID in the contact-form script in `index.html`. Until configured, visitors can use the email address shown on the website.
